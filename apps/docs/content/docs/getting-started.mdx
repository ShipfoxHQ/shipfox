Your coding agent builds Shipfox workflows for you. Connect it, then tell it
what to build.

## Before you begin

- Complete onboarding in [Shipfox](https://app.shipfox.io), with a project for
  your repository.
- Open that repository in Claude Code, Codex CLI, or OpenCode.

## Connect your coding agent

Add the Shipfox MCP server to your coding agent:

<include>../snippets/connect-coding-agent.mdx</include>

## Start building

Start from a template. The agent suggests the ones that fit your workspace:

<AgentHandoff
  skill="create-workflow-from-template"
  prompt="Use Shipfox to create a workflow from a template."
/>

<ForHumans>
To pick one yourself, copy its prompt from [Examples](/examples).
</ForHumans>

Or describe your own workflow:

<AgentHandoff
  skill="write-a-workflow"
  prompt="Use Shipfox to write a workflow for this repository."
/>

The agent asks a few questions, tests the workflow on your repository, and
opens a pull request. Merge it to turn the workflow on.
