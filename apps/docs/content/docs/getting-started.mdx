Your coding agent sets up a workflow that turns a task into a tested pull
request. You connect the agent, paste one prompt, and merge two pull requests.

## Before you begin

- Complete onboarding in [Shipfox](https://app.shipfox.io), with a project for
  a GitHub repository.
- Open that repository in Claude Code or Codex CLI.

The test run uses runner time and model inference, like any other run.

## Set up your first workflow

<Steps>
  <Step>

    **Connect your coding agent**

    In Claude Code, run this command in the repository:

    ```sh
    claude mcp add --transport http shipfox https://api.shipfox.io/mcp
    ```

    Run `/mcp`, select **shipfox**, and sign in. For Codex CLI, see [Connect a
    Coding Agent](/how-to/set-up-work/connect-mcp-client).
  </Step>
  <Step>

    **Paste the prompt**

    ```text
    Use Shipfox to create a workflow from the ticket-to-pr template, without the tracker part.
    ```

    Answer the agent's questions. It finds your test commands, proposes a small
    task from your repository, and starts a test run.
  </Step>
  <Step>

    **Merge the two pull requests**

    The test run opens a **task pull request** with the change. Leave a review
    comment and the agent pushes a fix. Merge it to ship the change.

    Then the agent opens a **workflow pull request**. Merge it to turn the
    workflow on.
  </Step>
</Steps>

## What you built

The workflow is on. Give it the next task through your coding agent:

```text
Start the Implement a task and open a pull request workflow in Shipfox with this task: <the change and how to check it>.
```
