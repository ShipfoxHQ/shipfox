## Access and repeated runs

ClickUp sends events only for items the connected account can see. Give the
service account access to every Space, Folder, and List you want to watch.

When a workflow changes a task, ClickUp sends another event. That event can
start the workflow again. Add a
[trigger filter](/reference/workflow-schema#trigger-fields) that ignores changes
from the service account. Match only fields that the workflow does not change.
