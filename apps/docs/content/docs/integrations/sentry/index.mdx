## Authentication

Shipfox connects through a Sentry App. Install the App in the target Sentry
organization and authorize its requested access.

Sentry tools read with the installation's access. They can read every project
that the installation can see in the organization.

## Integration connection identity

The slug of a Sentry integration connection defaults to `sentry_<organization>`, such
as `sentry_acme`. Use the slug of the workspace integration connection as a workflow
trigger `source`, or as `connection` in an agent integration or tool step.

```yaml
triggers:
  on_issue:
    source: sentry_acme
    event: issue.created
```

For trigger field rules, see the [workflow schema reference](/reference/workflow-schema#trigger-fields).
