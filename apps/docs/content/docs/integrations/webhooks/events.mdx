Shipfox accepts JSON, form, and plain-text bodies. Each accepted request gets a
`202 Accepted` response with a `delivery_id`. Give retries the same
`X-Delivery-ID` header. Shipfox creates an ID when the header is missing.

## Event catalog

Custom webhook triggers use only `source`. Use your custom webhook integration
connection slug instead of `deploy_hook`.
