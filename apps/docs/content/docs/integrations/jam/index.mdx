Jam records bug reports in the browser. The Jam integration lets your
workflows read these bug reports.

A Jam contains:

- The video or the screenshots
- The console logs and the network requests
- The clicks and the pages that the reporter opened
- The device and the browser
- The narration of the reporter

## Authentication

Shipfox uses a Jam personal access token. The token starts with `jam_pat_`. It
must have MCP read access.

The token belongs to one Jam user and one Jam workspace. Shipfox can read only
the Jams that this user can see.

Jam tokens expire. When the token expires, tool calls fail. The integration
connection then shows `error`. To fix it,
[replace the token](/integrations/jam/setup#replace-the-token).
