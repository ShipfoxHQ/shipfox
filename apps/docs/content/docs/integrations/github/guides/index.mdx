Each guide completes one GitHub task in a workflow. You need a
[GitHub integration connection](/integrations/github/setup) first.

<Cards>
  <Card title="Manage repository access" href="/integrations/github/guides/manage-repository-access">
    Change the GitHub repository list and Shipfox access mode.
  </Card>
  <Card title="Give agents GitHub tools" href="/integrations/github/guides/read-pull-request">
    Grant an agent read-only GitHub context.
  </Card>
  <Card title="Let agents write to GitHub" href="/integrations/github/guides/post-pull-request-review">
    Grant one agent step a narrow GitHub write.
  </Card>
  <Card title="Report check runs" href="/integrations/github/guides/add-check-runs">
    Publish a command's progress and result as a GitHub check run.
  </Card>
  <Card title="Push commits from a job" href="/integrations/github/guides/push-repository-changes">
    Check an agent's local edit and push it to a new branch.
  </Card>
</Cards>

For complete workflows that use GitHub, see the [recipes](/how-to/recipes). Use
the [GitHub tool catalog](/integrations/github/tools) to look up tool selectors
and permissions.
